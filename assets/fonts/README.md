# Bundled fonts

These fonts are used by the Windows UI. The macOS theme continues to use its
system fonts.

- Inter 4.1: `InterVariable.ttf`
  - Source: https://github.com/rsms/inter/releases/tag/v4.1
  - License: SIL Open Font License 1.1 (`Inter/LICENSE.txt`)
- Noto Sans JP: `NotoSansJP-VariableFont_wght.ttf`
  - Source: https://github.com/google/fonts/tree/2d85e20401920891efb7cd6272d6339685df2820/ofl/notosansjp
  - License: SIL Open Font License 1.1 (`NotoSansJP/LICENSE.txt`)
